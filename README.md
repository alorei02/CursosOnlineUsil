# USIL Cursos Online

Tienda online de cursos desarrollada como proyecto académico para la tarea de DevOps.

## Tecnologías usadas

- Next.js
- React
- TypeScript
- Tailwind CSS
- Git y GitHub
- Vercel para despliegue

## Ejecutar en local

```bash
npm install
npm run dev
```

Abrir en el navegador:

```text
http://localhost:3000
```

## Subir a GitHub

```bash
git init
git add .
git commit -m "Proyecto tienda de cursos USIL"
git branch -M main
git remote add origin https://github.com/TU-USUARIO/usil-cursos-online.git
git push -u origin main
```

## Desplegar en Vercel

1. Entrar a Vercel.
2. Crear un nuevo proyecto.
3. Importar el repositorio de GitHub.
4. Mantener Framework Preset: Next.js.
5. Presionar Deploy.
6. Copiar el dominio generado por Vercel.
