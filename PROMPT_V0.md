Crea una tienda de cursos online para USIL llamada "USIL Cursos Online". Debe ser una landing page moderna y responsive con estilo académico/corporativo, usando colores azul institucional, dorado y blanco. La página debe incluir: header con navegación, hero principal, catálogo de cursos, buscador, filtros por categoría, tarjetas de cursos con precio, duración, nivel y botón de agregar al carrito, resumen de carrito, sección de beneficios, sección de stack DevOps y footer.

Cursos de ejemplo: DevOps desde cero, Marketing Digital para Emprendedores, Diseño UX/UI con prototipos, Análisis de Datos con Excel y Power BI, Gestión Ágil con Scrum y Ciberseguridad para Usuarios. El carrito debe permitir simular agregar cursos y mostrar el total. En la sección DevOps indicar: Next.js, React, TypeScript, Tailwind CSS, Git, GitHub, Vercel, CI/CD, revisión visual y pruebas manuales.

Usa Next.js, React, TypeScript y Tailwind CSS. El resultado debe quedar listo para desplegar en Vercel.
