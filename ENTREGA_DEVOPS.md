# Entrega DevOps - Tienda de cursos online USIL

## Nombre del proyecto

USIL Cursos Online

## Descripción

Se desarrolló una tienda de cursos online orientada a estudiantes y profesionales de USIL. La página permite visualizar un catálogo de cursos, filtrar por categoría, buscar cursos por texto y simular la compra agregando cursos a un carrito. El objetivo del proyecto es presentar una solución web moderna, clara y desplegada en la nube mediante un flujo básico de DevOps.

## Stack DevOps utilizado

### Frontend

Se utilizó Next.js con React para crear una aplicación web moderna, modular y compatible con despliegues en Vercel. TypeScript se empleó para mejorar la calidad del código y reducir errores durante el desarrollo.

### Estilos

Se utilizó Tailwind CSS para diseñar una interfaz visual rápida, limpia y responsive. El diseño se adaptó para escritorio y dispositivos móviles.

### Control de versiones

Se utilizó Git para registrar los cambios del proyecto y GitHub como repositorio remoto. Esto permite mantener historial de versiones, facilitar la colaboración y conectar el proyecto con Vercel.

### Despliegue

Se utilizó Vercel como plataforma de hosting. Al conectar GitHub con Vercel, cada actualización enviada al repositorio puede generar un nuevo despliegue automáticamente.

### Integración y entrega continua

El flujo DevOps aplicado fue: desarrollo local, control de versiones con Git, publicación del código en GitHub y despliegue en Vercel. Este proceso permite entregar cambios de forma rápida y ordenada.

### Calidad y validación

La validación se realizó mediante revisión visual de la página, prueba del buscador, prueba de filtros por categoría, prueba del carrito y verificación del diseño responsive.
